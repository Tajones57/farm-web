FARM HORIZON - PHP + MySQL setup (XAMPP + VS Code)

1. Copy the whole "farm-horizon" folder into  C:\xampp\htdocs\
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Open http://localhost/phpmyadmin  ->  Import tab  ->  choose sql/database.sql  ->  Go.
   (This creates the "farm_horizon" database with all tables and 6 products.)
4. If your MySQL has a password, change it in includes/config.php.
5. Open http://localhost/farm-horizon/  -> Sign up -> shop.
6. Open the folder in VS Code: File > Open Folder > farm-horizon.

Pages:  login.php  signup.php  menu.php  product.php  cart.php  checkout.php  done.php  account.php
CSS:    css/style.css     JS: js/script.js     Images: images/
